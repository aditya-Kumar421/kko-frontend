### **Installation**

1. **Clone the repository**
   ```bash
   git clone https://github.com/prakharAKGa/kmrl-knowledge-orchestrator.git
   cd kmrl-knowledge-orchestrator
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm start
   ```

4. **Open your browser**
   Navigate to [http://localhost:3000](http://localhost:3000)

### **Environment Setup**
Set `REACT_APP_API_BASE_URL` in the root `.env` file to configure the backend API URL. `.env` and update the value as needed. Restart the development server after changing environment variables.

To learn React, check out the [React documentation](https://reactjs.org/).
